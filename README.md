# Carol Sheets
This is a simple file to extract lyrics from lilypond files and create a carol sheet with a title and an image on the front page.

## Running order of carols

- Silent Night
- While Shepherds watched
- In the bleak midwinter
- Away in a Manger
- Good King Wencelas
- Once in Royal David's city
- O little town of Bethlehem
- Hark! the herald angels sing
- O Come all we faithful
- A partidge in a pear tree
